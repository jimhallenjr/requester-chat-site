# Requester Chat documentation site

Static GitHub Pages site for 3825 IT Solutions. No app credentials or private install package belong in this repository.

Before publishing, the publisher must approve privacy.html and terms.html as its public policies and confirm the business name/contact details. Pricing is the user-selected USD $5 per agent/month; availability remains pending approval.

## Publish
Create a public repository named requester-chat-site under the publisher-owned GitHub account. Upload all site files to main. In Settings > Pages choose Deploy from a branch, main, /(root). The final URL is https://jimhallenjr.github.io/requester-chat-site/. Replace the account with the actual publisher account; do not submit a placeholder URL.

Use /support.html, /privacy.html, /terms.html and /demo.html for listing fields. The source app and private Marketplace package are intentionally excluded.

No analytics, cookies, forms or payment checkout are included. Do not add trackers without updating the policy. GitHub Pages hosting may log request metadata.

This is documentation and support, not an e-commerce checkout. App purchases are handled only through Freshworks Marketplace after approval.

The initial remote repository is private while the publisher reviews the policy/terms. Making it public and enabling Pages will publish all files. Only documentation/media are included.
